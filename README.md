# 🏆 Kaggle Competitions Portfolio

This repository showcases my **Kaggle competition projects**, where I explore real-world datasets, apply data preprocessing, perform exploratory data analysis (EDA), and build machine learning & deep learning models.

Each folder contains:
- 📊 Jupyter Notebooks with EDA and modeling
- 🧹 Data preprocessing scripts
- 📈 Model training and evaluation
- 📝 Notes and observations
